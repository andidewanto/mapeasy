# MapEasy

**English** · [Bahasa Indonesia](#bahasa-indonesia)

Cylinder Wrap (image around a cylinder) and Face Fill (image fitted to faces). Free SketchUp extension by Andi Dewanto — Windows & macOS, SketchUp 2021+. Version **1.1.0**.

- Website: https://andidewanto.github.io/mapeasy/
- Download: [`downloads/ad_mapeasy-1.1.0.rbz`](downloads/ad_mapeasy-1.1.0.rbz)
- Tutorial (English / Indonesian): https://andidewanto.github.io/mapeasy/tutorial.html
- Install: SketchUp › **Extensions › Extension Manager › Install Extension…** › choose the `.rbz`.
- More extensions: https://andidewanto.github.io/sketchup-extensions/

Contact & bug reports: andidewanto@gmail.com
